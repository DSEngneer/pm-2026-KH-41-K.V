## 1. Definition of Workflow

| Колонка | Картка потрапляє сюди, коли | Картка виходить звідси, коли |
| --- | --- | --- |
| Backlog | Задача у форматі ТЗ, стартова точка | Задача розкинута на підзадачі та є перевіреною та готова до початку роботи |
| Ready | Якщо відповідає DOR, без прихованих деталей всі вхідні дані готові для роботи |Виконавець бере картку в розробку за умови наявності місця в колонці In progress.  |
| In progress |Робота розпочата і є в процесі, перетягнута сюди Виконавцем |Роботу завершено, артефакт створено локально, виконано базові вимоги завдання. |
| Review |Артефакт завантажено в репозиторій або підготовлено до перевірки, перевірка вимогам в процесі |виконано перевірку за вимогою, код або документ влито в основну гілку. |
| Done | Вимога до DOD є пройденою, є коміт в main, правки не потрібні. |Фінальний стан |
